# Security

Report a vulnerability in Van Helsing's contracts or its SDK by email to
[security@nexroute.io](mailto:security@nexroute.io), not in a public issue or pull request.

Include what you found, the contract or SDK version it affects, how to reproduce it (a test, or
transactions on a fork of BNB Chain), and what an attacker could do with it. Please give us time
to fix it before you disclose it.
